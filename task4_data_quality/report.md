# 4. Kiểm tra và xử lý chất lượng dữ liệu

## Input chung

`data/raw/AirPassengers.csv` gồm 144 dòng, hai cột `date,value`, không missing và không trùng ngày. Giữ nguyên file này để các task khác sử dụng.

## Phần thực hành

1. Kiểm tra schema, missing và duplicate của file gốc.
2. Tạo một bản sao có một số `NaN` giả lập.
3. Xử lý bản sao bằng forward-fill và interpolation.
4. So sánh kết quả trước và sau xử lý.
5. Kiểm tra outlier bằng rolling statistics, z-score hoặc IQR.
6. Lưu biểu đồ và dữ liệu mô phỏng trong `task4_data_quality/output/`.
