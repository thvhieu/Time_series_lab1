# Time Series Group Skill

1. Đọc `data/processed/series.csv` theo contract `date,value`.
2. Giữ từng module chạy độc lập.
3. Lưu hình vào thư mục riêng dưới `artifacts/`.
4. Viết test bằng pytest và lưu log chạy vào `evidence/`.
5. Mỗi người tự viết section Markdown của module.
6. Chỉ tích hợp vào `main` sau khi script và test pass.
