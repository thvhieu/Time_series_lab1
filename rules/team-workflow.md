# Team workflow rules

- `main` chỉ chứa code đã chạy và được review.
- Mỗi người làm trên branch `task/<module>`.
- Không sửa file thuộc module của người khác nếu chưa trao đổi.
- Không dùng đường dẫn tuyệt đối theo máy cá nhân.
- Mỗi module phải có code, test, artifact, report section và evidence.
- Dataset canonical là `data/processed/series.csv` với schema `date,value`.
- Code freeze: 11/10/2026. Report freeze: 12/10/2026.
